# Demo and screenshot guidance

The maintained portfolio evidence is the [public CivicFlow demo](https://civicflow-request-tracker.muznaimran328.chatgpt.site). It shows the current resident submission flow, administrator dashboard, request lifecycle, reporting, and responsive layouts.

This repository intentionally does not include static application captures. The live demo prevents stale screenshots from misrepresenting the current build and avoids accidentally publishing browser, operating-system, account, or database details.

If screenshots are added later:

- use clearly fictional requests and general locations;
- keep credentials, cookies, developer tools, personal bookmarks, and local paths out of frame;
- show a useful product state rather than an empty queue;
- crop consistently and add concise alt text;
- review every image for personal or operational data before committing it.
